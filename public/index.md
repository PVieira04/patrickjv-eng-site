## About

I design and run the foundations other engineers build on: architecture, infrastructure, identity and security, and the engineering standards that hold them together.

Much of my recent work is about making AI-assisted delivery trustworthy. I hold agent-written code to the same standard as anyone's: a written spec before code, tests first, a hook that stops an agent finishing until typecheck, lint and tests pass, and adversarial review by a model from a second vendor.

I do my best work where a small team needs to operate like a much larger one: setting technical direction through architecture decision records, choosing platforms on measured evidence, and automating the work nobody should do by hand.

## Work

### Internal developer platform for AI-assisted delivery

A Claude Code platform for a whole engineering team: a plugin of 21 skills and 3 hook events for spec-first authoring, test-driven implementation and cross-vendor adversarial review, plus a versioned engineering-standards baseline that fans out automatically to about 26 repositories.

Tags: Agentic AI · Developer Experience · CI/CD

### Agent execution and evaluation platform

An agent execution and evaluation platform. Coding agents take specified work, build in sandboxed containers with per-run credentials, pass rubric-graded review gates and merge on automated criteria. The platform choice was settled by a measured spike: 3.3 s cold start, 32 ms warm.

Tags: AI Agents · Cloudflare Containers · Queues

### Passkey and verifiable-credential identity

Built from scratch: did:web identity with WebAuthn passkeys and W3C Verifiable Credentials, in production as the sign-in for a suite of internal applications, with federation to self-hosted DIDs — including this domain.

Tags: WebAuthn · did:web · Verifiable Credentials

### Infrastructure as code

Cloud and SaaS infrastructure run through Terraform Cloud with GitOps — plan on pull request, apply on merge, daily drift detection — across GitHub, Cloudflare, Kafka, Databricks and observability. AWS and Microsoft 365 as code; joiners and leavers automated.

Tags: Terraform · GitOps · Cloudflare

### On-premises speech intelligence

A meeting-transcription pipeline on an NVIDIA DGX Spark — NeMo ASR, diarisation and voiceprint speaker naming — for audio that cannot leave the building.

Tags: NVIDIA NeMo · ASR · On-prem AI
