Method
The analysis uses the continuous front‑month future supplied by **synth‑1m** (column *close* values). The raw timestamps in the dataset are UTC; they are converted to *America/New York*. Each session is defined as 18:00–17:00 NY, dated by its ending day. Bars that fall outside this window are discarded. Because the data set already implements a synthetic continuous contract (the *contract* column rolls automatically), we treat it as a single continuous series – no additional roll‑handling logic is required. For every session we: 1) identify the first closing price at or immediately after 18:00 NY of day D; 2) identify the last closing price at or immediately before 17:00 NY of day D+1; 3) compute the session log return as **ln(close_end / close_start)**. The daily series of log returns is then used for inference.
Statistic
log_return_2024
Significance
A two‑sample (paired, because each observation is a single day’s return) t‑test with degrees of freedom n‑1 (n = number of trading sessions in 2024). The null hypothesis H0: μ = 0 versus the alternative Ha: μ ≠ 0. If the two‑sided p‑value < 0.05 we reject H0 at the 5 % level.

Critic

Review: Did not pass review

  • Overlap autocorrelation: The analysis uses a standard two‑sample t‑test on daily session log–returns, assuming independent observations. In high‑frequency data aggregated into non‑overlapping 24‑hour windows, the daily returns are typically serially correlated (due to overnight carry, intra‑day dynamics, etc.). Without applying HAC (Newey–West) standard errors, block bootstrapping or a similar correction, the reported SE and p‑value may be understated. The conclusion that the mean return differs from zero could therefore be overstated.
  • Contract roll: The synthetic ``synth-1m`` series includes contract switches at 2024‑03‑07 14:30 UTC (≈9:30 NY), 2024‑06‑13 13:30 UTC, 2024‑09‑12 13:30 UTC and 2024‑12‑12 14:30 UTC. Each of these roll points lies inside a session window (18:00 previous day to 17:00 current day). The code assumes the price series is fully back‑adjusted so that no price jump occurs at a contract switch; however, this assumption is not verified in the analysis. If a jump were present and unadjusted, it would inflate a session’s return for the roll‑day and bias both the cumulative log return and the t‑test result.

Method

The analysis uses the continuous front‑month future supplied by **synth‑1m** (column *close* values). The raw timestamps in the dataset are UTC; they are converted to *America/New York*. Each session is defined as 18:00–17:00 NY, dated by its ending day. Bars that fall outside this window are discarded. For every session we: 1) identify the first closing price at or immediately after 18:00 NY of day D; 2) identify the last closing price at or immediately before 17:00 NY of day D+1; 3) compute the session log return as **ln(close_end / close_start)**. Code

import pandas as pd, numpy as np
import research_io
import scipy.stats as st
# Load data
df = research_io.load('synth-1m')
# Filter by symbol and year
mask_sym = df['symbol'] == 'SYN'
start_ts = pd.Timestamp('2024-01-01T00:00:00Z')
end_ts   = pd.Timestamp('2024-12-31T23:59:59Z')
mask_year = (df['ts'] >= start_ts) & (df['ts'] <= end_ts)
df_yr = df[mask_sym & mask_year].copy()
# Ensure timezone aware
if df_yr['ts'].dt.tz is None or df_yr['ts'].dt.tz.utcoffset(df_yr['ts'].iloc[0]) is None:
    df_yr['ts'] = df_yr['ts'].dt.tz_localize('UTC')
ny_tz = 'America/New_York'
# Convert timestamps to NY timezone
df_yr['ts_ny'] = df_yr['ts'].dt.tz_convert(ny_tz)
# Define session boundaries: each session ends 17:00 NY on date D, starts previous day 18:00 NY
date_range = pd.date_range(start='2024-01-02', end='2024-12-31', freq='D', tz=ny_tz)
session_bounds = []
for d in date_range:
    sess_end = d.replace(hour=17, minute=0, second=0, microsecond=0)
    sess_start = (d - pd.Timedelta(days=1)).replace(hour=18, minute=0, second=0, microsecond=0)
    session_bounds.append((sess_start, sess_end))
# Compute log returns for each session
returns=[]
for sstart, send in session_bounds:
    mask_sess = (df_yr['ts_ny'] >= sstart) & (df_yr['ts_ny'] <= send)
    sess_df = df_yr.loc[mask_sess].sort_values('ts')
    if sess_df.empty:
        continue
    # Use the first and last closing prices in the session window
    price_start = sess_df.iloc[0]['close']
    price_end   = sess_df.iloc[-1]['close']
    returns.append(np.log(price_end/price_start))
ret_series = pd.Series(returns)
n_sessions = len(ret_series)
mean_ret  = ret_series.mean()
se_mean   = ret_series.std(ddof=1)/np.sqrt(n_sessions) if n_sessions>0 else np.nan
pval = 2*st.t.sf(abs(mean_ret)/se_mean, df=n_sessions-1) if se_mean>0 else np.nan
ci_low  = mean_ret - st.t.ppf(0.975, n_sessions-1)*se_mean if n_sessions>1 else np.nan
ci_high = mean_ret + st.t.ppf(0.975, n_sessions-1)*se_mean if n_sessions>1 else np.nan
cum_log_return = ret_series.sum()
# Save result and answer
dict_result = {
    'n_sessions': int(n_sessions),
    'mean_session_log_return': float(mean_ret),
    'se_mean_session_log_return': float(se_mean) if not pd.isna(se_mean) else None,
    'p_value': float(pval) if not pd.isna(pval) else None,
    'ci_low_95': float(ci_low) if not pd.isna(ci_low) else None,
    'ci_high_95': float(ci_high) if not pd.isna(ci_high) else None,
    'cumulative_log_return_2024': float(cum_log_return)
}
answer = {
    "statistic": "log_return_2024",
    "value": cum_log_return,
    "n": n_sessions,
    "conclusion": "supported" if pval<0.05 else "not_supported",
    "ci": {"level": 0.95, "low": ci_low, "high": ci_high}
}
research_io.save_result(dict_result, answer=answer)
print('Done')

Critic findings

  • Pass 1: revise
    • contract_roll: The plan assumes that the synthetic continuous contract in *synth‑1m* is already back‑adjusted so that no price jump occurs at the listed roll times (e.g., 2024‑03‑07 14:30 UTC, 10:30 NY). If these rolls are not adjusted, a session log return could include an artificial jump when a new contract takes over inside the session, contaminating the calculated mean and its standard error. The plan should explicitly verify that no discontinuity occurs at each roll or apply a back‑adjustment (or drop any return that straddles a roll). Without this check, the reported statistic `log_return_2024` may be biased and the hypothesis test invalid.
  • Pass 2: revise

As noted in the dataset description, the synthetic continuous series is already back‑adjusted so that price jumps at roll dates are smoothed out. Skipping these sessions unnecessarily reduces the sample size and can bias the mean log‑return estimate by discarding days that contain no genuine market move. The correct approach is to keep all sessions (or explicitly apply a back‑adjustment if the raw series were used). This logic deviates from the plan’s stated assumption that the continuous series requires no additional roll handling.
