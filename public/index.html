About

I design the architecture and run the infrastructure, identity and security that other engineers build on, and I write the engineering standards they work to.

Much of my recent work is about making AI-assisted delivery trustworthy. Agent-written code goes through the same checks as anyone's: a written spec before code, tests first, a hook that stops an agent finishing until typecheck, lint and tests pass, and adversarial review by a model from a second vendor.

I do my best work in small teams. I set technical direction by writing architecture decision records, choose platforms on measured evidence, and automate any job nobody should be doing by hand.

Platform engineering, AI-assisted software delivery, infrastructure as code and passkey-based identity, mainly with TypeScript, Python, Cloudflare and Terraform.
